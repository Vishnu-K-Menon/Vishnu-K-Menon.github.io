# Vishnu Krishnakumar Menon · Portfolio

Personal portfolio of Vishnu Krishnakumar Menon, AI/ML Engineer (LLM evaluation, AI reliability, RAG and inference infrastructure).

Live at **https://vishnukrishnakumarmenon.com**

## Structure

- `index.html` – page shell
- `data/*.json` – all content (hero, about, experience, projects, skills, education, contact, footer)
- `assets/css/styles.css`, `assets/js/main.js` – Blueprint theme styling and rendering
- `assets/images/` – headshot, company logos, project thumbnails
- `assets/files/` – resume

## Run locally

```bash
python -m http.server 8000
```

Then open http://localhost:8000.
